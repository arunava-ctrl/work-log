# Work Log

A daily work log with streaks, XP, timers and automatic backups. Everything stays on your device —
no account, no server.

**Use the app: https://arunava-ctrl.github.io/work-log/**

- Log tasks, notes and pictures for each day; mark days in progress or completed
- Start/stop timer, or add time by hand (hand-entered time counts toward hours but earns no XP)
- Streaks, levels and achievements, with seven colour themes
- Automatic backup to a file you pick (Chrome/Edge), or download a backup on any browser
- Install it from the browser menu ("Install app" / "Add to Home screen") to use it offline

There is also an Android app with the same features that backs up to the phone's Documents folder.
